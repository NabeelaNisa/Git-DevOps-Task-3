# Git & GitHub Deployment Project

## Project Overview
This project demonstrates Git and GitHub-based source code management and application deployment using Docker and Nginx.

## Technologies Used
- Git
- GitHub
- Docker
- Nginx
- AWS EC2 Ubuntu

## Implementation

1. Installed and configured Git.
2. Created a GitHub repository.
3. Cloned the repository to the AWS EC2 Linux server.
4. Created an HTML application.
5. Added and committed project files.
6. Pushed changes to GitHub.
7. Pulled repository updates.
8. Created a feature branch.
9. Modified the application in the feature branch.
10. Merged the feature branch into main.
11. Pushed both branches to GitHub.
12. Deployed the application using Docker and Nginx.

## Docker Deployment

- Container name: git-deploy-web
- Docker image: nginx:alpine
- Host port: 8083
- Container port: 80

## Testing Results

- Git installation and configuration verified.
- GitHub repository created and synchronized.
- Branching and merging completed successfully.
- Docker container running successfully.
- Application returned HTTP 200 OK.

## Conclusion

The project successfully demonstrates Git and GitHub source code management and a basic application deployment workflow using Docker and Nginx.
